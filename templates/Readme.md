# JWT Auth App
This project is starting as a home application for SSO. It provides features like Sign-Up, Login and Redirect.
The current version of App is jwt-auth-app:1.0.0
This connects to the DB, checks the user info validates and should be able to generate a JWT auth token for Authorization.


# Architecture
 - MariaDB: User Database
 - Docker Image: App server
 - Kubernetes: Hosting

## Technologies
 - MariaDB SQL for Database
 - Python for Application backend
 - Jinja2 for Application Frontend
 - Docker containers
 - Kubernetes for deployment and hosting engine
